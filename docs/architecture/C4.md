# Journey — Architecture (C4 model)

Status: **Living**
Last updated: 2026-07-26

> [C4](https://c4model.com) describes software at four zoom levels: **Context →
> Container → Component → Code**. We maintain the top three as Mermaid (the Code level is
> the source itself). See `docs/ARCHITECTURE.md` for the rationale and ADR-0001/0002 for
> the decisions.

---

## Level 1 — System Context

Who uses Journey and what it talks to.

```mermaid
flowchart TB
    user([User<br/>maps goals & traits])
    subgraph journey[Journey system]
        app[Journey<br/>web app]
    end
    openai[OpenAI<br/>Whisper + GPT]
    tg[Telegram<br/>Bot API]
    ig[Instagram<br/>inbound]

    user -->|uses| app
    app -->|transcribe + structure| openai
    tg -->|media & links| app
    ig -->|media & links| app
```

## Level 2 — Containers

The deployable/runnable pieces and their data.

```mermaid
flowchart TB

```

## Level 3 — Components

### Frontend (SPA) — maps to `src/`

```mermaid
flowchart TB
    subgraph features[features/ · React UI slices]
        canvas[canvas]
        panel[panel]
        traits[traits]
        auth[auth]
        app[app shell]
    end
    state[state/ · Zustand stores<br/>graph, camera, selection, drag, choose, auth, journeys]
    domain[domain/ · pure TS<br/>graph/DAG, geometry/LOD, status, color, types]
    render[render/ · PixiJS adapter<br/>CanvasRenderer + canvasBridge]
    apiclient[api/ · HTTP client]

    features -->|read + dispatch| state
    state -->|pure logic| domain
    render -->|subscribes to| state
    render -->|hit-test / create goal| domain
    canvas -->|mounts| render
    features -->|calls| apiclient
    apiclient -->|HTTP| server[(API)]
```

**Key seam:** the `render` layer never owns state — it subscribes to `state` and uses
`domain` for pure math. React never re-renders the WebGL scene (ADR-0002).

### Backend (API) — maps to `server/`

```mermaid
flowchart TB
    index[index.mjs<br/>Express app, auth, journeys, attachments]
    telegram[telegram.mjs<br/>ingestion]
    ai[ai.mjs<br/>transcribe + structure]
    db[(SQLite)]
    openai[OpenAI]

    index -->|SQL| db
    index --> telegram
    index --> ai
    ai --> openai
    telegram --> db
```
