# Feature Specs

A **spec** is the short document a feature is built from — the AI-native, spec-driven
unit of work. You (and the agent) work *from* the spec; review happens on the spec and
the diff, not just the code.

## How to use

1. Copy [`_template.md`](_template.md) to `NNNN-short-title.md` (append-only numbering).
2. Fill in the problem, requirements (reuse/extend `UC-`/`REQ-` ids from
   `docs/USE-CASES.md`), design notes, and a test plan.
3. Implement against it; reference the ids in test names.
4. When shipped, set status to **Done** and link the PR.

Specs are living until Done, then frozen as a record. New behavior gets a new spec.
